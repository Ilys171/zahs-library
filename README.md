# ZAL Digital Library

A full-stack digital library prototype for Akademik Zərifə Əliyeva Lyceum.

## Features

- Student login using a 4-digit school code
- Book catalog with filtering and search
- Temporary book borrowing system
- Loan duration based on book length
- Protected PDF reading route through backend
- SQLite database
- Node.js + Express backend

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite

## Run Locally

```bash
npm install
npm start
```
